# Ali Agent — Personal AI Companion

A Python-based voice-enabled AI companion that greets me every day, tracks my coding streak, and keeps me accountable on my journey to becoming a Python & AI Engineer.

## Features (v1.0)
- 🎙️ Voice greeting using offline text-to-speech (pyttsx3)
- 📅 Displays current date and day of the week
- 🔥 Tracks daily coding streak with JSON persistence
- 🛡️ Prevents cheating — cannot increment streak twice in one day
- 🗣️ Spoken confirmation when streak is updated

## Tech Stack
- Python 3.11
- pyttsx3 (offline text-to-speech)
- JSON for data persistence
- datetime for date handling

## Roadmap
- v1.1 — More motivational quotes, weekday/weekend variation
- v2.0 — Integration with Anthropic/OpenAI API for conversational AI
- v2.5 — Automatic morning launch via Windows Task Scheduler
- v3.0 — Web interface + VPS deployment

## Setup
```bash
python -m venv venv
source venv/Scripts/activate  # Windows
pip install -r requirements.txt
python ali_agent.py
```
